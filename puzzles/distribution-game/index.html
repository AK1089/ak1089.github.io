The Distribution Game

published December 24, 2026

This puzzle concerns a two-player game, which we set up as follows.

Two players choose a probability distribution over [0, ∞)[0, \, \infty)[0,∞) with mean μ=1\mu = 1μ=1. Then, each player independently draws a number from their distribution. The player with the highest number wins (in the event of a tie, the game is replayed). What is the Nash equilibrium?
