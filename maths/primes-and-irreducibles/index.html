Primes and Irreducibles in Rings

published May 29, 2024, updated October 25, 2026

In school, you were likely taught that a prime number is a number with precisely two positive factors (itself and 111). You were likely also taught a useful property of primes: if p∣abp \mid abp∣ab, that is if a prime ppp is a factor of some product of two numbers, then it is a factor of one of those numbers. If a×b=8645a \times b = 8645a×b=8645, then either aaa or bbb is a multiple of 555. This is generally not true for composite numbers: 4∣60=6×104 \mid 60 = 6 \times 104∣60=6×10, even though 444 is a factor of neither 666 nor 101010.

Unfortunately, this definition is backwards! The latter property is in fact the true essence of a prime number—the former actually describes an irreducible number. These coincide among the integers we are familiar with, but they are subtly different. Let’s explore these two definitions and see where they come apart.

An element rrr in an integral domain (a ring with no nontrivial zero divisors: a⋅b=0Ra \cdot b = 0_Ra⋅b=0R​ implies a=0Ra = 0_Ra=0R​ or b=0Rb = 0_Rb=0R​) RRR is called irreducible if r≠0Rr \neq 0_Rr=0R​, rrr is not a unit (that is, ∀a∈R,a⋅r≠1R\forall a \in R, a \cdot r \neq 1_R∀a∈R,a⋅r=1R​), and if r=xyr = xyr=xy then either xxx or yyy is a unit.

Similarly, an element rrr is called prime if r≠0Rr \neq 0_Rr=0R​, rrr is not a unit, and if r∣xyr \mid xyr∣xy then either r∣xr \mid xr∣x or r∣yr \mid yr∣y. In a ring, an element ddd divides an element aaa, written d∣ad \mid ad∣a, if there exists some element r∈Rr \in Rr∈R such that d⋅r=ad \cdot r = ad⋅r=a.

In the ring of integers Z\mathbb{Z}Z, the primes are in fact exactly the irreducibles. This is not generally true, as we will see in the main example. However, we do have the following result.

Primes Are Always Irreducible

  1. Suppose r∈Rr \in Rr∈R is a prime, and r=a⋅br = a \cdot br=a⋅b for two non-unit elements aaa and bbb.
  2. Since r=1R⋅rr = 1_R \cdot rr=1R​⋅r, we have r∣r=a⋅br \mid r = a \cdot br∣r=a⋅b. Then, as rrr is prime, r∣ar \mid ar∣a or r∣br \mid br∣b.
  3. Without loss of generality (we’re only considering commutative rings here), suppose r∣ar \mid ar∣a, ie. r⋅d=ar \cdot d = ar⋅d=a for some d∈Rd \in Rd∈R.
  4. Then, r=a⋅b=(r⋅d)⋅b=r⋅(d⋅b)r = a \cdot b = (r \cdot d) \cdot b = r \cdot (d \cdot b)r=a⋅b=(r⋅d)⋅b=r⋅(d⋅b).
  5. Then, as we are in an integral domain, d⋅b=1Rd \cdot b = 1_Rd⋅b=1R​, which means bbb is a unit.
  6. Thus rrr is irreducible.

But Not Vice Versa

Now, we look at the ring R=Z[−5]={a+b−5:a,b∈Z}≤CR = \mathbb{Z}[\sqrt{-5}] = \{a + b \sqrt{-5} : a, b \in \mathbb{Z}\} \leq \mathbb{C}R=Z[−5​]={a+b−5​:a,b∈Z}≤C. As this is a subring of a field (a ring in which every nonzero element is a unit, like C\mathbb{C}C), it is an integral domain.

Consider the norm function given by

N:R→N0,a+b−5↦a2+5b2. N: R \to \mathbb{N}_0, a + b \sqrt{-5} \mapsto a^2 + 5b^2. N:R→N0​,a+b−5​↦a2+5b2.

Note that this maps z∈Cz \in \mathbb{C}z∈C to ∣z∣2|z|^2∣z∣2, and satisfies N(z⋅w)=N(z)⋅N(w)N(z \cdot w) = N(z) \cdot N(w)N(z⋅w)=N(z)⋅N(w).

This is a really useful property! If r⋅s=1r \cdot s = 1r⋅s=1, then

N(r⋅s)=N(r)⋅N(s)=N(1)=1  ⟹  N(r)=N(s)=1. N(r \cdot s) = N(r) \cdot N(s) = N(1) = 1 \implies N(r) = N(s) = 1. N(r⋅s)=N(r)⋅N(s)=N(1)=1⟹N(r)=N(s)=1.

So any unit a+b−5a + b \sqrt{-5}a+b−5​ has to satisfy N(a+b−5)=a2+5b2=1  ⟹  a=±1,b=0N(a + b \sqrt{-5}) = a^2 + 5b^2 = 1 \implies a = \pm 1, b = 0N(a+b−5​)=a2+5b2=1⟹a=±1,b=0.

Thus the only possible units are 111 and −1-1−1, which are obviously both units (as 1⋅1=−1⋅−1=11 \cdot 1 = -1 \cdot -1 = 11⋅1=−1⋅−1=1), so they are precisely the two units of RRR.

Note that there are clearly no elements of norm 222 or 333: any such element rrr would be nonzero and require

5b2≤N(r)<5  ⟹  b<1  ⟹  b=0,andN(r)<4  ⟹  ∣a∣<2  ⟹  a=±1 5b^2 \leq N(r) < 5 \implies b < 1 \implies b = 0, \quad \text{and} \quad N(r) < 4 \implies |a| < 2 \implies a = \pm 1 5b2≤N(r)<5⟹b<1⟹b=0,andN(r)<4⟹∣a∣<2⟹a=±1

but then these are just the units again, so there are no such elements.

With this in mind, we claim that 2∈R2 \in R2∈R is irreducible. Suppose 2=a⋅b2 = a \cdot b2=a⋅b. Then

N(a)⋅N(b)=N(2)=4  ⟹  N(a)=1,  N(b)=4 (in some order). N(a) \cdot N(b) = N(2) = 4 \implies N(a) = 1, \; N(b) = 4 \quad \text{ (in some order).} N(a)⋅N(b)=N(2)=4⟹N(a)=1,N(b)=4 (in some order).

Thus aaa or bbb has norm 111 and so is a unit, hence 222 is irreducible as required.

In the same way, we can demonstrate that the elements 3,1+−5,3, 1 + \sqrt{-5},3,1+−5​, and 1−−51 - \sqrt{-5}1−−5​ are irreducible too.

Importantly, 222 does not divide either of 1±−51 \pm \sqrt{-5}1±−5​. Suppose 2⋅r=1±−52 \cdot r = 1 \pm \sqrt{-5}2⋅r=1±−5​. Then we would have 4⋅N(r)=6  ⟹  N(r)=1.54 \cdot N(r) = 6 \implies N(r) = 1.54⋅N(r)=6⟹N(r)=1.5, which is not possible, as the norm function NNN maps to N0\mathbb{N}_0N0​.

Now, note that

(1+−5)⋅(1−−5)=6=2⋅3 (1 + \sqrt{-5}) \cdot (1 - \sqrt{-5}) = 6 = 2 \cdot 3 (1+−5​)⋅(1−−5​)=6=2⋅3

So 2∣6=(1+−5)⋅(1−−5)2 \mid 6 = (1 + \sqrt{-5}) \cdot (1 - \sqrt{-5})2∣6=(1+−5​)⋅(1−−5​), but neither 2∣(1+−5)2 \mid (1 + \sqrt{-5})2∣(1+−5​) nor 2∣(1−−5)2 \mid (1 - \sqrt{-5})2∣(1−−5​). Thus by definition, 222 cannot be prime in RRR.

So in general, irreducible elements in integral domains are not necessarily prime.

(Also, factorisation of ring elements into irreducibles is not necessarily unique. The rings in which this property holds are called unique factorisation domains.)
